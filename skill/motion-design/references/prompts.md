# Prompt library

Each prompt is a start; always add brand folder + facts + size/fps/duration.

- **Single scene** — "Using the motion-design skill, build one 6 s scene: [what appears], camera push-in, masked headline, spring entrances staggered 60 ms. Probe 4 stills first."
- **Brand film** — "20 s brand film, 120 BPM, 5 scenes on the beat map, colour flood into the product, end card with shared-element logo handoff. Brief first, then stills."
- **UI transformation** — "Show [screen A] morphing into [screen B]: shared elements fly, new cards spring in, camera in log-space zoom to the changed area, ‘Example data’ label."
- **Launch reveal** — "Tease with kinetic type on a dark field, drop on the beat into the live product, 3 feature beats, URL end card; music break lands on the reveal frame."
- **LinkedIn loop** — "1080×1080, 8 s seamless loop; end state == start state in position and velocity; run qc.py --loop."
- **Revision** — "Make the transitions faster / change the music / add a 3D cube on the drop" — edit code, re-render only `--from/--to` of the touched scene.
